貼上內容 URL

支援 HTTPS Instagram 貼文、Reel、單則 Story、帳號當下 Story 清單與 X 狀態貼文 URL。/stories/帳號/ 列出清單（最多 20 則），加數字 ID 只取單則。超量不截斷；帳號首頁、Stories tray 與 Highlights 不支援。可存取範圍取決於平台與部署驗證設定。

請只下載你有權保存的內容。可信部署若使用服務管理者的 Instagram 工作階段，任何服務使用者都可能間接存取該帳號可見的私人或受眾限定 Story。結果與下載參照僅暫時保留。

    桌面書籤工具

    把下方連結拖到書籤列，不要直接點它。在 Instagram 或 X 來源頁點書籤，即可在新分頁帶入網址；確認後再按「分析」。

    送到 SNS Media List

    無法拖曳時，手動新增書籤，命名為「送到 SNS Media List」，將下方完整安裝碼貼入書籤的網址欄位。

    服務地址變更後請重新安裝。只讀來源網址，不讀 Cookie 或頁面內容；若瀏覽器或網站政策阻擋，請改用手動貼上。
